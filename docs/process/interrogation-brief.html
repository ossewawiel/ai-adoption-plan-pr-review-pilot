New this turn: the plugin as the enforcement and measuring mechanism

Managed settings install and lock plugins across an organisation
This is the mechanism behind “every team pulls it in”. Anthropic's documentation states that managed settings decide which plugins Claude Code installs and allows on every machine, and that users cannot override them.
